# 🎨 Assets

This directory contains visual assets for the **Triple Threat Arena Simulator** project.

## Files

### `logo.svg`
The **primary horizontal logo** (800×400) for the project. Features:
- Cinematic title "TRIPLE THREAT ARENA SIMULATOR" in gold chrome
- Octagon ring in 3D isometric perspective
- Three stylized fighter silhouettes (Trump/Putin/Kim) on the ring
- Volumetric RGB spotlights (red/amber/blue) shining down
- HD broadcast scanlines and corner brackets
- "LIVE HD" + "AI-POWERED" badges

**Recommended usage:** GitHub README header, project documentation, social media banners.

### `logo-icon.svg`
A **square icon variant** (512×512) of the logo, optimized for:
- App icons / favicons
- Social media profile pictures
- Browser tabs and bookmarks
- Compact brand representations

## Color Palette

The logo uses the project's primary color scheme:

| Color | Hex | Usage |
|-------|-----|-------|
| **Amber Gold** | `#fbbf24` | Primary brand color, titles, ring |
| **Red** | `#ef4444` | Trump fighter, danger / live indicator |
| **Blue** | `#3b82f6` | Putin fighter, technical / info |
| **Orange** | `#ffa254` | Trump skin tone |
| **Black** | `#000000` | Background, contrast |
| **White** | `#ffffff` | Text highlights |
